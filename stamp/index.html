// 💡 【重要】ここに先ほどデプロイ画面でコピーした「新しいGASのURL」を貼り付けてください const apiUrl = "ここに新しいGASのURLを貼り付け"; async function sendStamp(userId, eventId) { const payload = { userId: userId, eventId: eventId, timestamp: new Date().toISOString() }; try { // 💡 mode: "no-cors" と headers を完全に削除しました const response = await fetch(apiUrl, { method: "POST", body: JSON.stringify(payload) }); // 💡 GASから返ってきたエラーメッセージなどをブラウザのコンソールで読めるようにします const resultText = await response.text(); console.log("GASからの返答:", resultText); } catch (error) { console.error("送信エラー:", error); } } window.onload = () => { const urlParams = new URLSearchParams(window.location.search); const eventId = urlParams.get("event") || "test"; const userId = "test-user"; sendStamp(userId, eventId); };
